#  Mamaearth Returns & Growth Intelligence Pipeline

This repository contains a three-layer e-commerce data analysis pipeline using **SQL, Python EDA/visualization, and AI-assisted business narration**.

## Repository Structure

```text
├── README.md
├── sql/
│   ├── schema.sql
│   ├── seed_data.sql
│   └── reports.sql
├── data/
│   ├── customers.csv
│   ├── products.csv
│   └── orders.csv
├── analysis/
│   ├── clean_and_eda.py
│   └── visualize.py
├── visualizations/
│   ├── return_rate_by_payment.png
│   └── monthly_revenue_trend.png
└── narrator/
    ├── findings.json
    └── generate_narrative.py
```

## Pipeline Order

Run the three layers **in this exact order**:

### 1. SQL Layer

Create the database and load the schema and seed data:

```bash
sqlite3 ecommerce.db < sql/schema.sql
sqlite3 ecommerce.db < sql/seed_data.sql
```

Run the SQL reports:

```bash
sqlite3 ecommerce.db < sql/reports.sql
```

The SQL layer creates the database tables from `schema.sql`, loads data from `seed_data.sql`, and produces the SQL-level reports and metrics.

### 2. Analysis Layer

Run data cleaning and exploratory analysis:

```bash
python analysis/clean_and_eda.py
```

This processes the raw CSV data, handles duplicates, missing values, and outliers, and calculates the cleaned business metrics.

**Task 5 of Part 2** writes the resulting findings to:

```text
narrator/findings.json
```

Next, generate the visualizations:

```bash
python analysis/visualize.py
```

The charts are saved in the `visualizations/` folder.

### 3. Narrator Layer

The narrator reads the findings generated by the analysis layer.

With a Gemini API key:

**Windows PowerShell:**

```powershell
$env:GEMINI_API_KEY="your_api_key"
python narrator/generate_narrative.py
```

Without an API key, run the same command:

```bash
python narrator/generate_narrative.py
```

The script automatically uses the **offline fallback path** when no API key is available.

### Output Flow

```text
CSV Data
   ↓
SQL Layer → SQL reports
   ↓
Python Cleaning & EDA
   ↓
narrator/findings.json
   ↓
Visualization Layer → visualizations/*.png
   ↓
Narrator Layer → SCR business narrative
```

Following the steps above from top to bottom reproduces the analysis numbers, findings, visualizations, and final narrative.
